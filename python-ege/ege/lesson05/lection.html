ЕГЭ №5. Преобразование двоичной записи

ТеорияПрактикаДомашнее задание
Перед уроком: 7, 8, 12. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Отделяйте число N от его двоичной строки и итогового числа R. Приписывание разрядов — строковая операция, вычисление остатка или суммы цифр — числовая.

Реализуйте преобразование отдельной функцией. Для поиска минимума уточните, что минимизируется: N или R. Если ответ ищется перебором, область должна следовать из условия либо быть обоснована.

Разобранный пример

К двоичной записи N дважды дописывают остаток суммы её цифр по модулю 2, каждый раз по текущей записи. Найдём наименьшее N, для которого R>100.

def transform(n):
    s = bin(n)[2:]
    for _ in range(2):
        s += str(s.count("1") % 2)
    return int(s,2)
n = 1
while transform(n) <= 100:
    n += 1
print(n, transform(n))

Вывод программы

25 102

После первой дописки число единиц становится чётным, поэтому второй дописанный бит равен 0. Два бита увеличивают длину на два, и R≥4N, значит поиск обязательно завершится не позднее N=26.

На что обратить внимание

Если сумма должна вычисляться по исходной записи оба раза, код будет другим. При поиске минимального R нельзя просто остановиться на первом N, если монотонность R не доказана.
