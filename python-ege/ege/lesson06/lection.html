ЕГЭ №6. Черепаха: траектории и целочисленные точки

ТеорияПрактикаДомашнее задание
Перед уроком: 24. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Сначала восстановите координаты всех вершин с учётом стартового направления, поворотов и положения пера. Затем сформулируйте область: внутри фигуры, на границе, в пересечении или объединении.

Python позволяет перебрать целочисленные точки в ограничивающем прямоугольнике. Для прямоугольных контуров используйте неравенства; для произвольного многоугольника понадобится отдельная проверка принадлежности. Рисунок turtle служит пояснением.

Разобранный пример

Две замкнутые траектории образуют прямоугольники [0;6]×[0;4] и [3;8]×[2;7]. Посчитаем точки их пересечения с границей.

count = 0
for x in range(0,9):
    for y in range(0,8):
        in_a = 0 <= x <= 6 and 0 <= y <= 4
        in_b = 3 <= x <= 8 and 2 <= y <= 7
        if in_a and in_b:
            count += 1
print(count)

Вывод программы

12

Обе проверки должны быть истинны. Пересечение — прямоугольник [3;6]×[2;4], поэтому число целых координат можно дополнительно получить произведением. Строгие неравенства исключили бы границу.

На что обратить внимание

При подсчёте объединения используйте or, не складывайте два количества: общие точки иначе учитываются дважды.
