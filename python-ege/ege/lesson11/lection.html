ЕГЭ №11. Кодирование идентификаторов и округление

ТеорияПрактикаДомашнее задание
Перед уроком: 2, 7. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Для алфавита мощности M минимальная фиксированная длина символа — наименьшее i с 2**i≥M. Для M≥2 её можно вычислить (M-1).bit_length().

Если каждый идентификатор из L символов занимает целое число байт, сначала округляют L*i вверх до байта, затем умножают на число записей. Дополнительные сведения прибавляют к размеру записи до умножения.

Разобранный пример

Алфавит содержит 70 символов, длина идентификатора 15, записей 1200. Дополнительных полей нет. Найдём объём.

M, L, N = 70, 15, 1200
bits = (M - 1).bit_length()
bytes_per_record = (L * bits + 7) // 8
print(bits, bytes_per_record, bytes_per_record * N)

Вывод программы

7 14 16800

Семи бит достаточно для 128 символов. 105 бит на идентификатор округляются до 14 байт. Нельзя сначала умножить 105 на 1200 и округлить общий объём: в условии каждая запись занимает целое число байт.

На что обратить внимание

Если хранение округляется до целых блоков, учитывайте размер блока. Мощность алфавита не равна длине идентификатора.
