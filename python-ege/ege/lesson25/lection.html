ЕГЭ №25. Делители, простые множители и числовые маски

ТеорияПрактикаДомашнее задание
Перед уроком: 15. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Подбирайте перебор под условие. Для кратности k проверяйте только кратные; для маски с малым числом неизвестных цифр генерируйте цифры; для делителей используйте пары до квадратного корня.

Произведение ровно двух простых множителей включает квадрат простого, если множители могут совпадать. Условия на запись множителей проверяйте отдельно, после установления простоты. Числа и дополнительные величины выводите в заданном порядке.

Разобранный пример

Найдём кратные 37 не больше 10000, подходящие маске 1?2*.

from fnmatch import fnmatchcase
for n in range(37,10001,37):
    if fnmatchcase(str(n),"1?2*"):
        print(n,n//37)

Вывод программы

1221 33
1628 44
1924 52

В range проверяются только нужные кратные. ? занимает одну цифру, * может быть пустой. Порядок возрастающий уже задан диапазоном. Верхняя граница включена через +1.

На что обратить внимание

Количество строк в бланке ответа не задаёт число искомых чисел. Для «первых пяти» останавливаются после пяти найденных, для «всех до границы» проходят весь диапазон.
