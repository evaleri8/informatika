ЕГЭ №20. Игра: гарантированная победа вторым ходом

ТеорияПрактикаДомашнее задание
Перед уроком: 20; ЕГЭ №19. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Позиция W1 позволяет победить сразу. Позиция L1 не позволяет победить текущему игроку, а любой его ход передаёт сопернику W1. Тогда W2 — позиция без победы сразу, из которой есть ход в L1.

Эта классификация реализует кванторы: выбираем собственный ход, учитываем любой ответ противника, затем выбираем победный ход. Она подходит для конечной игры с возрастающей мерой состояния.

Разобранный пример

Для игры из №19 найдём S, при которых Петя гарантированно выигрывает своим вторым ходом, но не первым.

T = 34
def moves(p):
    a,b=p
    return ((a+2,b),(a,b+2),(2*a,b),(a,2*b))
def w1(p):
    return sum(p)<T and any(sum(q)>=T for q in moves(p))
def l1(p):
    return sum(p)<T and not w1(p) and all(w1(q) for q in moves(p))
def w2(p):
    return sum(p)<T and not w1(p) and any(l1(q) for q in moves(p))
print([s for s in range(1,29) if w2((5,s))])

Вывод программы

[7, 10, 11, 12, 13]

Переход в L1 заставляет соперника вернуть позицию W1 при любом ответе. Отдельное not w1(p) выполняет требование невозможности победы первым ходом.

На что обратить внимание

Если игра допускает ничьи или циклы, такая простая рекурсивная классификация не охватывает все случаи. Здесь сумма строго растёт.
