ЕГЭ №1. Графы и таблицы дорог

ТеорияПрактикаДомашнее задание
Перед уроком: 10, 14, 19. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Задача сопоставления схемы и таблицы требует восстановить соответствие вершин. Сначала сравните степени вершин и их соседей. Вес ребра используется после установления соответствия.

Python может перебрать перестановки меток и проверить сохранение всех рёбер и отсутствующих рёбер. Для n вершин это n! вариантов, поэтому такой подход разумен для небольших схем. Если соответствий несколько, проверьте, одинаков ли запрашиваемый результат.

Разобранный пример

Дана схема с рёбрами AB, AC, AD, BC, BD и таблица с рёбрами 12, 13, 14, 23, 34. Найдём все соответствия, сохраняя граф полностью.

from itertools import permutations
names = "ABCD"
edges = {frozenset(e) for e in ("AB", "AC", "AD", "BC", "BD")}
table = {frozenset(e) for e in ((1,2),(1,3),(1,4),(2,3),(3,4))}
solutions = []
for p in permutations(range(1,5)):
    mapping = dict(zip(names,p))
    mapped = {frozenset(mapping[v] for v in e) for e in edges}
    if mapped == table:
        solutions.append(mapping)
print(len(solutions))
for m in solutions: print(m)

Вывод программы

4
{'A': 1, 'B': 3, 'C': 2, 'D': 4}
{'A': 1, 'B': 3, 'C': 4, 'D': 2}
{'A': 3, 'B': 1, 'C': 2, 'D': 4}
{'A': 3, 'B': 1, 'C': 4, 'D': 2}

frozenset делает ребро неориентированным: AB равно BA. Равенство множеств проверяет и наличие, и отсутствие связей. Несколько найденных отображений здесь естественны из-за симметрии графа.

На что обратить внимание

Не выдавайте первое соответствие за единственное. Табличные номера — метки, а не длины дорог.
