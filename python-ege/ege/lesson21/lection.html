ЕГЭ №21. Игра: выигрыш первым или вторым ответом

ТеорияПрактикаДомашнее задание
Перед уроком: 20; ЕГЭ №19–20. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Чтобы второй игрок гарантированно выиграл своим первым или вторым ходом, каждый первый ход соперника должен вести в W1 или W2. При этом исключают ситуации, где второй гарантированно выигрывает уже первым ходом.

Удобно определить L2: все переходы ведут в W1∪W2, но не все — в W1. Терминальные переходы первого игрока недопустимы, потому что игра уже окончилась его победой.

Разобранный пример

Для той же игры найдём S, соответствующие такой стратегии Вани.

T=34
def moves(p):
    a,b=p
    return ((a+2,b),(a,b+2),(2*a,b),(a,2*b))
def w1(p):
    return sum(p)<T and any(sum(q)>=T for q in moves(p))
def l1(p):
    return sum(p)<T and not w1(p) and all(w1(q) for q in moves(p))
def w2(p):
    return sum(p)<T and not w1(p) and any(l1(q) for q in moves(p))
def l2(p):
    return sum(p)<T and all(w1(q) or w2(q) for q in moves(p)) and not all(w1(q) for q in moves(p))
print([s for s in range(1,29) if l2((5,s))])

Вывод программы

[5]

Если есть ход Пети сразу к цели, соответствующий q не принадлежит W1 или W2, и условие all отклонит позицию. Последняя часть исключает L1, то есть гарантированную победу Вани только первым ответом.

На что обратить внимание

«Первым или вторым» допускает разный срок победы при разных ходах соперника. Это не требование выиграть ровно вторым при каждом ходе.
