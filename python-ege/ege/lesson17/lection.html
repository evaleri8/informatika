ЕГЭ №17. Файл последовательности: соседние пары и тройки

ТеорияПрактикаДомашнее задание
Перед уроком: 9, 13. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Если условие использует общий минимум, максимум или среднее по файлу, сначала найдите эту характеристику. Затем выполняйте проход по соседним группам.

«Хотя бы один» — or, «оба» — and, «ровно один» — неравенство булевых условий. Храните отдельно количество групп и требуемый экстремум. Начальное значение None корректно и для отрицательных результатов.

Разобранный пример

Подсчитаем соседние пары, в которых хотя бы один элемент кратен 3, и найдём максимальную сумму.

a = [5, 6, -3, 8, 11, 12]
count = 0
best = None
for x,y in zip(a,a[1:]):
    if x % 3 == 0 or y % 3 == 0:
        count += 1
        s = x + y
        best = s if best is None else max(best,s)
print(count,best)

Вывод программы

4 23

zip связывает соседние позиции, не создавая все возможные пары. Для тройки используйте индексы до len(a)-3 включительно. В исходной последовательности порядок сохраняется.

На что обратить внимание

Окончание отрицательного числа на 7 можно проверять abs(x)%10==7, если речь о последней цифре модуля. Сравните это с остатком x%10 для отрицательных.
