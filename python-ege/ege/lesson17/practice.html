ЕГЭ №17. Файл последовательности: соседние пары и тройки — Практика

ТеорияПрактикаДомашнее задание
Выполните задания последовательно. Сначала запишите алгоритм, затем создайте программу.

Задание 1

По practice.txt, где по одному целому в строке, решите задачу примера.

Задание 2

Найдите количество соседних пар, где ровно один элемент оканчивается на 7 по модулю, и минимальную сумму.

Задание 3

Найдите среднее всех чисел файла, затем число соседних троек с суммой больше утроенного среднего.

Что сдать

Файлы программ с понятными именами, полученные результаты и краткое объяснение алгоритма. Для заданий на объяснение — текст с обоснованием. В программах, читающих файл, укажите его имя и формат; не включайте служебный вывод в итоговый ответ.
