ЕГЭ №23. Кратчайший путь и число путей в графе

ТеорияПрактикаДомашнее задание
Перед уроком: 19. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

В проекте 2027 №23 посвящён графам. Веса могут быть вещественными, вершины — иметь непоследовательные номера, а строки рёбер — любой порядок. Не считайте направление равным возрастанию номера.

Для неотрицательных весов подходит Дейкстра с очередью приоритетов. Для DAG также можно найти топологический порядок и выполнить динамику. Число путей считают суммированием, а кратчайшую длину — минимумом сумм весов.

Разобранный пример

Найдём кратчайший путь из 1 в 100 в ориентированном графе с положительными весами.

from heapq import heappush, heappop
g={1:[(7,5.5),(6,2.0)],6:[(7,1.0)],7:[(100,4.2)],100:[]}
dist={1:0.0}
heap=[(0.0,1)]
while heap:
    d,v=heappop(heap)
    if d != dist[v]: continue
    for u,w in g.get(v,[]):
        nd=d+w
        if nd < dist.get(u,float("inf")):
            dist[u]=nd
            heappush(heap,(nd,u))
print(dist[100])
print(int(dist[100]))

Вывод программы

7.2
7

Очередь выбирает ближайшую ещё актуальную запись. Устаревшие записи пропускаются. Целая часть берётся один раз после вычисления полной длины; округление каждого ребра меняет задачу. Для десятичных весов у целочисленной границы можно читать Decimal либо масштабировать в целые.

На что обратить внимание

Дейкстра не подходит для отрицательных весов. В DAG возможны отрицательные веса при динамике по топологическому порядку, но в данном примере веса положительны.
