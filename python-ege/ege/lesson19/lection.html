ЕГЭ №19. Игра: возможность победы после хода соперника

ТеорияПрактикаДомашнее задание
Перед уроком: 20. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Формулировка «Ваня выиграл первым ходом» без гарантии означает существование подходящего первого хода Пети и затем победного ответа Вани. Это не то же самое, что победа Вани при любой игре Пети.

В двух кучах сохраняйте оба числа. Из списка первого хода исключайте уже терминальные позиции: если Петя завершил игру, Ваня не получает ход. Все параметры игры вынесите в начало.

Разобранный пример

Две кучи (5,S), команды +2 к одной куче или удвоение одной; цель — сумма не меньше 34. Найдём минимальное S, при котором возможна победа Вани первым ходом.

T = 34
def moves(a,b):
    return ((a+2,b),(a,b+2),(2*a,b),(a,2*b))
def win1(a,b):
    return a+b<T and any(x+y>=T for x,y in moves(a,b))
possible = []
for s in range(1,29):
    if any(x+y<T and win1(x,y) for x,y in moves(5,s)):
        possible.append(s)
print(min(possible))

Вывод программы

8

Внешний any выбирает возможный ход Пети, внутренний — победный ответ Вани. Начальная сумма строго меньше 34. Если условие дополнительно запрещает Пете выиграть сразу, это отдельный фильтр.

На что обратить внимание

Не заменяйте внешний any на all без требования гарантии. Всегда указывайте, чья перспектива у функции win1.
