ЕГЭ №15. Логические выражения с параметром

ТеорияПрактикаДомашнее задание
Перед уроком: 3, 5, 14. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Для фиксированного A проверяйте формулу на всех существенных x. all соответствует требованию «при любом x», any — «существует x».

Бесконечную область нельзя заменить произвольным range(10000). Сначала докажите, за пределами какого диапазона формула истинна автоматически или повторяется. Для интервалов исследуют границы, для делимости — кратные, для битовых операций — разряды.

Разобранный пример

Найдём наибольшее натуральное A, для которого (10≤x≤30 и x кратно 6) → x кратно A истинно при любом натуральном x.

candidates = []
for A in range(1,31):
    if all((not (x % 6 == 0)) or x % A == 0 for x in range(10,31)):
        candidates.append(A)
print(max(candidates))

Вывод программы

6

Вне отрезка посылка ложна, поэтому импликация истинна автоматически. Внутри достаточно проверить кратные 6: 12,18,24,30. A обязано делить 12, значит A≤12; диапазон до 30 заведомо покрывает все ответы. Здесь конечность перебора обоснована.

На что обратить внимание

Для непрерывных отрезков перебор целых не проверяет все вещественные x. Для таких задач нужно рассматривать границы и промежутки между ними.
