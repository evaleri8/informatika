ЕГЭ №4. Префиксные коды и условие Фано

ТеорияПрактикаДомашнее задание
Перед уроком: 7, 8, 14. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

При условии Фано ни одно кодовое слово не является началом другого. Это достаточное условие однозначного декодирования слева направо без разделителей.

Двоичное дерево помогает найти свободные ветви. Python полезен для проверки набора и перебора коротких дополнений. Минимальную суммарную длину сообщения считают с учётом частот букв.

Разобранный пример

Для кодов A=0, B=10 подберём кратчайший код C.

from itertools import product
codes = ["0", "10"]
for length in range(1,6):
    found = []
    for chars in product("01", repeat=length):
        word = "".join(chars)
        if all(not word.startswith(c) and not c.startswith(word) for c in codes):
            found.append(word)
    if found:
        print(found)
        break

Вывод программы

['11']

Проверяются обе стороны отношения префикса. Длины перебираются по возрастанию, поэтому первая непустая группа даёт кратчайшие варианты. Ограничение 5 здесь достаточно, поскольку свободная ветвь видна уже на втором уровне.

На что обратить внимание

Разные кодовые слова ещё не гарантируют условие Фано. Если требуется обратное условие Фано, проверяются окончания, а не начала.
