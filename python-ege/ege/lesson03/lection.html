ЕГЭ №3. Связанные таблицы и отбор записей

ТеорияПрактикаДомашнее задание
Перед уроком: 10, 13. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Таблицы соединяются по ключам: код товара связывает продажу со справочником, код магазина — с адресом. Нельзя соединять строки по их текущему порядку.

Для Python экспортируйте каждый лист в CSV с понятными заголовками. Справочник удобно превратить в словарь по идентификатору. Сначала отберите нужные записи, затем вычисляйте количество, массу или стоимость с правильными единицами.

Разобранный пример

Найдём число проданных тетрадей по двум учебным таблицам.

goods = {1: ("тетрадь", 20), 2: ("ручка", 35)}
sales = [(1,3), (2,2), (1,5)]
total = 0
for code, quantity in sales:
    name, price = goods[code]
    if name == "тетрадь":
        total += quantity
print(total)

Вывод программы

8

Ключ code выбирает товар. В total складывается количество, а не число строк продаж. Для стоимости нужно умножать quantity на соответствующую цену.

На что обратить внимание

Возвраты и поступления могут иметь другой знак или тип операции. Среднее по строкам и средневзвешенное по количеству — разные величины.
