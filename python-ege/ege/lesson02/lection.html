ЕГЭ №2. Логическая функция и порядок переменных

ТеорияПрактикаДомашнее задание
Перед уроком: 3, 14. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Стройте таблицу значений функции на всех наборах 0 и 1. Импликацию переносите как (not P) or Q, эквивалентность — как ==. Скобки сохраняют структуру формулы.

Если столбцы перемешаны, перебирайте их соответствия переменным. При пропусках нужно также перебрать неизвестные ячейки и проверить различие строк таблицы. Нельзя сопоставлять столбцы по одному удачному набору.

Разобранный пример

Для F=(x → y) и (y ≡ z) выведем все наборы, на которых F истинна.

from itertools import product
for x,y,z in product((0,1), repeat=3):
    f = ((not x) or y) and (y == z)
    if f:
        print(x,y,z)

Вывод программы

0 0 0
0 1 1
1 1 1

Всего наборов восемь. Фильтр выбирает только строки с F=1. Если в задании приведены нули функции, условие меняется на if not f. Значения x,y,z остаются числами 0 и 1.

На что обратить внимание

Выражение x <= y кодирует импликацию только для булевых или 0/1 значений. Формула с not и or понятнее и безопаснее при переносе.
