ЕГЭ №9. Строки электронной таблицы

ТеорияПрактикаДомашнее задание
Перед уроком: 9, 10, 13. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Экспортируйте нужный диапазон в текст без лишних заголовков и убедитесь, что все числа строки сохранены. В Python каждая строка становится отдельным списком.

Условия повторений проверяйте частотами. «Все различны» означает len(set(row))==len(row). После сортировки минимальный и максимальный элементы находятся на концах, но сортировать следует отдельную строку.

Разобранный пример

Для пяти чисел проверим: все различны и удвоенная сумма крайних по величине больше суммы остальных.

rows = [[1,2,3,4,9], [2,2,3,4,10], [3,4,5,6,7]]
count = 0
for row in rows:
    a = sorted(row)
    if len(set(a)) == 5 and 2 * (a[0] + a[-1]) > sum(a[1:-1]):
        count += 1
print(count)

Вывод программы

2

Второе условие сравнивает две величины. Срез [1:-1] содержит только средние три числа. Каждая подходящая строка увеличивает счётчик на один, независимо от суммы её чисел.

На что обратить внимание

«Повторяется одно число дважды» не равно «есть повтор». У строки могут быть две пары или тройка одинаковых значений.
