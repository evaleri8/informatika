Выполните задания последовательно. Сначала запишите алгоритм, затем создайте программу.

Задание 1

По practice.txt найдите максимальную длину выражения по условию примера. Файл содержит одну строку; удалите только перевод строки.

Задание 2

Найдите максимум, если выражение обязано содержать хотя бы одну операцию.

Задание 3

Для строки 00--6*07-8 вручную перечислите самые длинные допустимые фрагменты и сопоставьте с программой.

Что сдать

Файлы программ с понятными именами, полученные результаты и краткое объяснение алгоритма. Для заданий на объяснение — текст с обоснованием. В программах, читающих файл, укажите его имя и формат; не включайте служебный вывод в итоговый ответ.
