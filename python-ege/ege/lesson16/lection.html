ЕГЭ №16. Рекуррентные функции и большие аргументы

ТеорияПрактикаДомашнее задание
Перед уроком: 16. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Сначала выясните зависимости. Если F(n) выражается через меньшие аргументы, можно вычислять снизу вверх. Рекурсия с кешем удобна для разветвлений, цикл — для длинных цепочек.

При отношениях факториалов и близких значений сократите выражение до вычисления. Это предотвращает переполнение стека и ненужное построение огромных чисел. Используйте //, если точная целочисленность доказана.

Разобранный пример

Пусть F(n)=n!. Вычислим (F(1002)+3F(1001))/F(1000).

n = 1002
answer = n * (n - 1) + 3 * (n - 1)
print(answer)

Вывод программы

1006005

F(1002)=1002*1001*F(1000), F(1001)=1001*F(1000). Общий множитель сокращается. Получается точное целое выражение, не требующее рекурсивных вызовов.

На что обратить внимание

Сокращение допустимо только для одинаковых множителей, а не отдельных слагаемых. В функциях с несколькими ветвями внимательно проверяйте область действия каждой.
