ЕГЭ №22. Зависимости процессов и параллельность

ТеорияПрактикаДомашнее задание
Перед уроком: 13, 16, 19. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Ранний старт процесса равен максимальному времени завершения всех его предшественников; при отсутствии зависимостей старт равен нулю. Завершение равно старт плюс длительность.

Зависимости образуют DAG. Порядок строк и числовые ID не обязаны быть топологическими. Используйте рекурсию с кешем либо топологическую сортировку. Для подсчёта одновременных процессов явно задайте временную шкалу.

Разобранный пример

Найдём интервалы выполнения четырёх процессов и количество работающих на четвёртой миллисекунде.

from functools import lru_cache
duration={1:3,2:4,3:2,4:5}
deps={1:[],2:[1],3:[2,4],4:[]}
@lru_cache(maxsize=None)
def finish(v):
    return duration[v]+max((finish(u) for u in deps[v]),default=0)
intervals={v:(finish(v)-duration[v],finish(v)) for v in duration}
t=4
print(sorted(intervals.items()))
print(sum(start <= t-1 < end for start,end in intervals.values()))

Вывод программы

[(1, (0, 3)), (2, (3, 7)), (3, (7, 9)), (4, (0, 5))]
2

Первая миллисекунда соответствует [0,1), четвёртая — [3,4). При целых длительностях достаточно проверять t-1. Процесс 3 ждёт оба предшественника, поэтому используется max, а не сумма.

На что обратить внимание

Значение 0 в таблице зависимостей часто означает отсутствие зависимостей, а не реальный процесс с ID=0. Не складывайте длительности параллельных ветвей.
