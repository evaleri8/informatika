ЕГЭ №13. Исполнители и количество программ

ТеорияПрактикаДомашнее задание
Перед уроком: 17. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

В проекте 2027 анализ программ исполнителя находится в №13. Состояние — число на экране, переход — допустимая команда. Если все переходы увеличивают число, получается DAG по значениям.

Различайте последовательность команд и последовательность состояний. Если две команды ведут в одну вершину, это обычно две программы. Дополнительные условия команды проверяются до формирования перехода.

Разобранный пример

Из 20 нужно получить 42. Команды: +1; поменять десятки и единицы, только если десятки меньше единиц. Считаем программы.

start, target = 20, 42
dp = [0] * (target + 1)
dp[start] = 1
for x in range(start,target + 1):
    nxt = [x + 1]
    tens, units = x // 10 % 10, x % 10
    if tens < units:
        nxt.append(x // 100 * 100 + units * 10 + tens)
    for y in nxt:
        if y <= target:
            dp[y] += dp[x]
print(dp[target])

Вывод программы

3

При разрешённой перестановке увеличение равно 9*(units-tens)>0, поэтому обход по возрастанию корректен. Старшие разряды сохранены через x//100*100. Переходы выше цели отбрасываются, так как уменьшения нет.

На что обратить внимание

Не разрешайте перестановку при равных цифрах: это создало бы петлю, если условие требует строгое неравенство.
