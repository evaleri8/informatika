ЕГЭ №27. Кластеризация по признаку и медоиды

ТеорияПрактикаДомашнее задание
Перед уроком: 11, 13, 23, 26. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

В проекте демоверсии 2027 частицы группируются по кинетической энергии E=m*(vx²+vy²)/2, а отдельная требуемая величина использует расстояние между координатами. Эти две метрики нельзя смешивать.

Центр выбирается среди частиц и минимизирует сумму модулей различий энергий. В одномерном случае это медиана; при гарантированной единственности центра её можно использовать после сортировки. Условие кластера max(E)-min(E)≤R не равно связности соседних значений.

После сортировки начинайте группу с минимальной оставшейся энергии и включайте следующие частицы, пока разность с первой не превосходит R. Так получается допустимое разбиение на группы диаметра ≤R. Затем обязательно сравните число групп с K: если оно равно K и условие гарантирует единственность разбиения, найденные группы являются искомыми. Если число групп не совпало, нельзя продолжать вычисление ответа: потребуется другой способ разбиения, например динамика по границам ровно K групп. Большие разрывы между соседними группами для этого способа не обязательны.

После выделения групп вычислите требуемый признак центра и расстояния только между частицами нужного типа внутри одной группы. Попарные расстояния дают O(m²) для m отобранных частиц; сравнивайте квадраты расстояний, извлекая корень один раз.

Разобранный пример

В data.txt по строкам: x y vx vy m type. Десятичная запятая допустима. Для учебного файла K=2, R=1; центры единственны. Найдём максимум расстояния между частицами II одного кластера и максимальную энергию центра.

from decimal import Decimal, localcontext
R=Decimal("1")
K=2
rows=[]
with open("data.txt",encoding="utf-8") as f:
    for line in f:
        parts=line.replace(",",".").split()
        x,y,vx,vy,m=map(Decimal,parts[:5])
        energy=m*(vx*vx+vy*vy)/2
        rows.append((energy,x,y,parts[5]))
rows.sort()
groups=[]
for row in rows:
    if not groups or row[0]-groups[-1][0][0]>R:
        groups.append([])
    groups[-1].append(row)
assert len(groups)==K
max_energy=max(g[len(g)//2][0] for g in groups)
max_d2=Decimal(0)
for g in groups:
    points=[(r[1],r[2]) for r in g if r[3]=="II"]
    for i,(x,y) in enumerate(points):
        for u,v in points[i+1:]:
            max_d2=max(max_d2,(x-u)**2+(y-v)**2)
with localcontext() as ctx:
    ctx.prec=40
    print(int(max_d2.sqrt()*10000),int(max_energy*10000))

Вывод программы

164924 42000

Энергии хранятся как Decimal, чтобы точно читать десятичные данные. Проверка len(groups)==K не позволяет молча принять разбиение с неверным числом кластеров. Группы отсортированы по энергии, медиана выбирает центр. Последние числа положительны, поэтому int берёт целую часть; формат ответа — одна строка из двух чисел. В общем двумерном варианте центра требуется медоид по заданной метрике, а не эта медиана.

На что обратить внимание

Единственность и число кластеров — существенные условия. Не объединяйте цепочку близких соседей, если крайние нарушают диаметр. Не округляйте координаты и энергии перед выбором центра.
