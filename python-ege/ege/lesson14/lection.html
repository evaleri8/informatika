ЕГЭ №14. Системы счисления: три основных типа

ТеорияПрактикаДомашнее задание
Перед уроком: 7, 14. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Тип 1: неизвестная цифра. Перебирайте значения от 0 до основания минус 1, вычисляйте значение многочлена разрядов и проверяйте делимость. Тип 2: число цифр большого выражения — деление с остатком.

Тип 3: поиск параметра в заданном диапазоне, влияющего на запись. Для максимума перебирайте диапазон в обратном порядке. Python хранит большие целые точно, но float и логарифмы могут давать пограничные ошибки.

Разобранный пример

Найдём цифры x в основании 12, для которых 2x3 делится на 7.

for x in range(12):
    value = 2 * 12**2 + x * 12 + 3
    if value % 7 == 0:
        print(x, value // 7)

Вывод программы

2 45
9 57

Число вычислено по позиционному принципу, поэтому неизвестную цифру не нужно заменять строкой. При основании больше 10 x — числовое значение цифры, а не обязательно один десятичный знак.

На что обратить внимание

Число 0 имеет запись из одной нулевой цифры. При подсчёте значащих нулей не добавляйте ведущие нули.
