ЕГЭ №12. Машина Тьюринга

ТеорияПрактикаДомашнее задание
Перед уроком: 10, 25. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Состояние модели включает ленту, позицию головки и внутреннее состояние. Одна команда сначала записывает символ, затем выполняет движение или остановку, после чего учитывается новое состояние.

В соглашениях демонстрационного варианта S означает завершение работы после записи. Для бесконечной в обе стороны ленты используйте словарь с пустым символом по умолчанию. Не подменяйте таблицу переходов привычной задачей «Редактор».

Разобранный пример

Машина начинает на левом символе 1010, в состоянии q. В состоянии q она меняет 0 на 1 и 1 на 0, двигаясь вправо; на пустом символе останавливается.

rules = {("q","0"):("1","R","q"), ("q","1"):("0","R","q"), ("q","_"):("_","S","q")}
tape = dict(enumerate("1010"))
pos, state = 0, "q"
steps = 0
while True:
    symbol = tape.get(pos,"_")
    new, move, state = rules[(state,symbol)]
    tape[pos] = new
    steps += 1
    if move == "S": break
    pos += 1 if move == "R" else -1
print("".join(tape.get(i,"_") for i in range(4)))
print(pos, steps)

Вывод программы

0101
4 5

Таблица полностью определяет поведение на достижимых парах. Пустая клетка справа имеет индекс 4. Команда остановки тоже выполнена, поэтому она входит в число шагов.

На что обратить внимание

Не обрезайте ведущий ноль итоговой ленты до выяснения, требуется ли строка символов или числовое значение. Пропущенное правило означает ошибку модели, а не автоматическую остановку.
