ЕГЭ №12. Машина Тьюринга — Домашнее задание

ТеорияПрактикаДомашнее задание
Выполните оба задания самостоятельно, используя приёмы урока.

Задание 1

Машина движется вправо по 11001, стирая единицы в _, нули сохраняя; на исходной пустой клетке останавливается. Реализуйте правила и выведите ленту в исходном диапазоне.

Задание 2

Для машины из второго задания практики определите десятичный результат на исходном числе 37. Объясните результат через длину двоичной записи.

Файлы программ с понятными именами, полученные результаты и краткое объяснение алгоритма. Для заданий на объяснение — текст с обоснованием. В программах, читающих файл, укажите его имя и формат; не включайте служебный вывод в итоговый ответ.
