Графы: списки смежности, обход и пути

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Вершины обозначают объекты, рёбра — связи. В ориентированном графе направление важно. Список смежности хранит соседей каждой вершины; для веса храните пары (сосед, вес).

BFS с очередью находит число рёбер кратчайшего пути в невзвешенном графе. Вершину отмечают при добавлении в очередь. Для взвешенных графов BFS не минимизирует сумму весов.

В ациклическом ориентированном графе возможна топологическая сортировка: все предшественники располагаются раньше вершины. В этом порядке можно считать число путей, минимальные и максимальные веса. Числовые метки вершин не гарантируют такого порядка.

Разобранный пример

Найдём минимальное число рёбер из A до остальных вершин.

from collections import deque
g = {"A": ["B", "C"], "B": ["D"], "C": ["D"], "D": []}
dist = {"A": 0}
q = deque(["A"])
while q:
    v = q.popleft()
    for u in g[v]:
        if u not in dist:
            dist[u] = dist[v] + 1
            q.append(u)
print(sorted(dist.items()))

Вывод программы

[('A', 0), ('B', 1), ('C', 1), ('D', 2)]

Очередь обрабатывает вершины слоями расстояния. Первый найденный путь по числу рёбер кратчайший. Словарь dist одновременно хранит расстояния и отмечает посещённые вершины.

На что обратить внимание

В неориентированном графе добавляйте обе стороны ребра. Для положительных весов используйте Дейкстру или динамику по топологическому порядку DAG.
