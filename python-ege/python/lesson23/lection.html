Эффективность: префиксные суммы и два указателя

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Оценка O(n) означает рост числа действий пропорционально n; O(n²) — квадратичный рост. Для миллионов элементов полный перебор пар обычно непрактичен. Сначала оцените объём данных и памяти.

Префиксная сумма p[k] хранит сумму первых k элементов, p[0]=0. Сумма от l до r включительно равна p[r+1]-p[l]. Подготовка занимает O(n), каждый запрос — O(1).

Два указателя поддерживают окно. Для неотрицательных элементов увеличение правой границы не уменьшает сумму, поэтому левую границу можно двигать только вперёд. При отрицательных значениях эта монотонность нарушается.

Разобранный пример

Найдём максимальную длину отрезка с суммой не больше 7 в неотрицательном списке.

a = [2, 1, 4, 2, 0, 3]
limit = 7
left = total = best = 0
for right, x in enumerate(a):
    total += x
    while total > limit:
        total -= a[left]
        left += 1
    best = max(best, right - left + 1)
print(best)

Вывод программы

4

После внутреннего цикла окно допустимо. Каждый элемент добавляется один раз и удаляется не более одного раза, поэтому два вложенных цикла здесь дают O(n), а не O(n²).

На что обратить внимание

Нельзя переносить этот алгоритм на произвольные отрицательные элементы. Размер программы не определяет её скорость.
