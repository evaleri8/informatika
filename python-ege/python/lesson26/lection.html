Что нужно понять

Кластеризация объединяет объекты по явно заданной мере близости. Координаты, энергия и другие признаки — разные пространства: нельзя выбирать метрику по внешнему виду таблицы.

Евклидово расстояние равно sqrt((x1-x2)**2+(y1-y2)**2). Медоид — один из исходных объектов с минимальной суммой расстояний до других. Среднее арифметическое координат обычно не является медоидом.

Для одномерной меры |a-b| минимум суммы достигается на медиане. Для нечётного числа различных значений медиана единственна. Условие диаметра кластера max-min ≤ R сильнее условия близости соседей.

Разобранный пример

Найдём медоид по абсолютной разности энергий у пяти объектов.

energies = [1.0, 1.2, 1.7, 2.0, 2.4]
center = min(energies, key=lambda e: sum(abs(e - x) for x in energies))
median = sorted(energies)[len(energies) // 2]
print(center, median)

Вывод программы

1.7 1.7

Перебор медоида требует O(n²) действий и удобен для маленького контрольного примера. В одномерном случае сортировка и медиана дают тот же результат быстрее. Для двухмерного евклидова расстояния медиана одного столбца не решает задачу.

На что обратить внимание

Цепочка значений 0, 0.9, 1.8 имеет соседние разрывы меньше 1, но диаметр 1.8. Нельзя объявлять её кластером диаметра не больше 1.
