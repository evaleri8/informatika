Что нужно понять

int хранит целые числа, float — приближённые вещественные. В записи дроби Python использует точку. Операторы: +, -, *, /, //, %, **. Обычное деление возвращает float, целочисленное деление округляет частное вниз.

Сначала вычисляются скобки, затем степень, умножение и деление, затем сложение. Для ясности группируйте выражения скобками. Для неотрицательных a и положительного b верно a = (a // b) * b + a % b.

Дробные значения float могут храниться неточно. Целое количество упаковок ёмкости k для n предметов вычисляют как (n + k - 1) // k при n ≥ 0, k > 0. Это позволяет избежать ошибок округления.

Разобранный пример

Разложим 3671 секунду на часы, минуты и секунды.

s = 3671
h = s // 3600
m = s % 3600 // 60
sec = s % 60
print(h, m, sec)

Вывод программы

1 1 11

Целые часы выделяются делением на 3600. Остаток после часов снова делится на 60. Последний остаток — секунды. Здесь все вычисления точны, потому что используются целые числа.

На что обратить внимание

Выражение int(a / b) не заменяет // для отрицательных чисел. Для денег с фиксированными копейками удобно хранить целое число копеек.
