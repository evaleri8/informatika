Что нужно понять

Регулярное выражение описывает множество строк. [0-9] — цифра, + — одно или больше повторений, * — ноль или больше, ? — необязательность предыдущего элемента. В регулярных выражениях ? и * имеют другой смысл, чем в масках fnmatch.

re.fullmatch проверяет всю строку, finditer выдаёт неперекрывающиеся совпадения. Для шаблона вещественного числа знак, десятичную точку и ведущие нули задают явно. Обычно шаблон записывают как r"...".

Для длиннейшего участка часто проще хранить состояние: текущую длину, последнюю позицию запрещённого символа, число нарушений. Сначала сформулируйте, что делает участок допустимым.

Разобранный пример

Найдём длину максимального участка без двух одинаковых соседних символов.

s = "ABBACABBA"
cur = best = 0
prev = None
for ch in s:
    cur = 1 if ch == prev else cur + 1
    best = max(best, cur)
    prev = ch
print(best)

Вывод программы

5

Если очередной символ равен предыдущему, допустимый суффикс начинается заново с одного символа. Иначе он удлиняется. best хранит максимум среди всех обработанных позиций. Время линейно по длине строки.

На что обратить внимание

Строка пустая: ответ 0. Точка в регулярном выражении означает любой символ; буквальную точку экранируют как \.. Не используйте eval для распознавания произвольного входного текста.
