Файлы, CSV и надёжное чтение данных

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

with open(..., encoding="utf-8") as f открывает текстовый файл и закрывает его после блока. Относительный путь отсчитывается от рабочей папки запуска. Для примеров держите программу и данные в одной папке и запускайте из неё.

split() без аргумента делит строку по любому непустому количеству пробельных символов. map(int, ...) применяет преобразование к каждому фрагменту. При чтении построчно не нужно хранить весь файл.

Сначала установите формат: есть ли заголовок, число записей N, разделитель ;, десятичная запятая. CSV читают модулем csv. Таблицы ODS/XLSX предварительно экспортируют в текст; переименование расширения не является преобразованием.

Разобранный пример

В data.txt записаны целые числа по одному в строке, без заголовка. Найдём их количество и сумму.

count = 0
total = 0
with open("data.txt", encoding="utf-8") as f:
    for line in f:
        if line.strip():
            total += int(line)
            count += 1
print(count, total)

Вывод программы

6 56

Каждая непустая строка превращается в число. В учебном примере пустые строки разрешены и пропускаются. В реальном задании нельзя молча пропускать повреждённые записи: формат задаёт условие.

На что обратить внимание

Если в первой строке N, не включайте его в последовательность. Не пытайтесь открыть ODS как обычный текст с числами.
