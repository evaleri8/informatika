Геометрия и исполнители на плоскости

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Положение исполнителя задают координатами и направлением. Для поворотов на 90 градусов можно работать с целыми векторами направления, избегая накопления ошибок float.

Точки на границе и строго внутренние точки считаются по-разному. Для прямоугольника строгая внутренняя область задаётся строгими неравенствами. Для многоугольника можно использовать знаки векторных произведений или алгоритм луча.

Модуль turtle помогает увидеть маршрут, но изображение не заменяет точный подсчёт. Масштаб рисунка не должен менять математические координаты. Для отладки сохраняйте список вершин траектории.

Разобранный пример

Посчитаем целочисленные точки строго внутри прямоугольника с вершинами (0,0), (5,0), (5,3), (0,3).

count = 0
for x in range(0, 6):
    for y in range(0, 4):
        if 0 < x < 5 and 0 < y < 3:
            count += 1
print(count)

Вывод программы

8

Диапазон перебора включает границу, а условие исключает её. Для прямоугольника тот же результат даёт произведение числа внутренних целых x и y. Для объединения областей применяют or, пересечения — and.

На что обратить внимание

Не считайте пиксели изображения. Уточняйте начальное направление исполнителя, положение пера и включение границы.
