Теория игр: any, all и выигрышные позиции

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

В игре с полной информацией стратегия задаёт ход для каждой возможной позиции. «Можно выиграть» означает существование подходящего хода; «при любой игре противника» требует проверки всех его ответов.

any проверяет существование истинного условия, all — истинность всех. Позиция выигрышна в один ход, если есть переход к цели. Проигрышна за один ответ, если все ходы передают противнику выигрыш в один ход.

Уточняйте, чей сейчас ход, кто уже выиграл и что означает срок «вторым ходом». Победа после неудачного хода соперника и гарантированная победа — разные вопросы.

Разобранный пример

Для игры +1 или *2 до достижения 15 найдём позиции выигрыша в один ход и проигрыша за один ответ.

T = 15
def moves(s):
    return (s + 1, s * 2)
def w1(s):
    return s < T and any(t >= T for t in moves(s))
def l1(s):
    return s < T and not w1(s) and all(w1(t) for t in moves(s))
print([s for s in range(1, T) if w1(s)])
print([s for s in range(1, T) if l1(s)])

Вывод программы

[8, 9, 10, 11, 12, 13, 14]
[7]

w1 требует хотя бы одного немедленно победного хода. l1 исключает собственную немедленную победу и требует, чтобы каждый ход давал сопернику w1. Цель 15 относится к общему правилу игры.

На что обратить внимание

Нельзя одинаково применять any на всех уровнях дерева. В двух кучах состояние храните парой, а каждый ход меняет только выбранную кучу.
