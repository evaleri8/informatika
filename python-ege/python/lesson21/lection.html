Битовые операции и IPv4

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

& выполняет поразрядное И, | — ИЛИ, ^ — исключающее ИЛИ, << и >> сдвигают разряды. Для неотрицательных чисел сдвиг влево на k соответствует умножению на 2**k.

IPv4 состоит из 32 бит. Маска содержит подряд единицы сети, затем нули узла. Адрес сети получается побитовым И адреса и маски. Префикс /p означает p единичных бит.

ipaddress.ip_network(address, strict=False) строит сеть по адресу узла. Перебор самой сети включает все адреса, а hosts() обычно исключает сетевой и широковещательный; выбирайте по условию.

Разобранный пример

Определим сеть, содержащую адрес 192.168.10.77 с префиксом /26.

from ipaddress import ip_network
net = ip_network("192.168.10.77/26", strict=False)
print(net.network_address)
print(net.netmask)
print(net.num_addresses)
print(sum(bin(int(ip)).count("1") % 2 == 0 for ip in net))

Вывод программы

192.168.10.64
255.255.255.192
64
32

Первые 26 бит фиксированы, оставшиеся 6 дают 64 адреса. Последняя строка считает адреса с чётным числом единиц во всей 32-битной записи. Ведущие нули на число единиц не влияют.

На что обратить внимание

Для подсчёта нулей дополните запись до 32 бит через format(int(ip), "032b"). Не перебирайте огромную сеть, если ответ получается по свободным битам.
