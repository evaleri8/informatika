Списки и обработка последовательностей

Что нужно понять

Список хранит изменяемую последовательность. append добавляет элемент; len, sum, min, max вычисляют основные характеристики. Для пустого списка min и max без default не определены.

Цикл по значениям удобен для суммы и фильтрации, по индексам — для соседних пар. enumerate выдаёт индекс и значение. Срез a[:] создаёт поверхностную копию списка.

a = b связывает два имени с одним списком. Изменение a может быть видно через b. Для независимой копии одномерного списка используйте b.copy().

Разобранный пример

Найдём количество соседних пар с чётной суммой и максимальную такую сумму.

a = [5, 7, 2, 4, 9]
count = 0
best = None
for i in range(len(a) - 1):
    s = a[i] + a[i + 1]
    if s % 2 == 0:
        count += 1
        if best is None or s > best:
            best = s
print(count, best)

Вывод программы

2 12

None означает отсутствие подходящей пары, поэтому алгоритм корректен и для отрицательных сумм. Пара задаётся индексами i и i+1, а не любыми двумя элементами.

На что обратить внимание

Не удаляйте элементы списка во время прямого перебора по нему. Создайте новый список подходящих значений.
