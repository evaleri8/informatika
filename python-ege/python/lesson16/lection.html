Рекурсия и кеширование

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Рекурсия — вызов функцией самой себя. Нужен базовый случай и изменение аргумента, ведущее к нему. Без этого вызовы не завершатся.

При повторяющихся подзадачах functools.lru_cache(maxsize=None) сохраняет результаты по аргументам. Он уменьшает повторную работу, но не устраняет глубину стека.

Для длинных цепочек используйте цикл или динамическое программирование. Искусственное увеличение предела рекурсии не заменяет выбор алгоритма. Для факториальных отношений часто сначала выгоднее сократить выражение алгебраически.

Разобранный пример

Вычислим числа Фибоначчи с кешированием.

from functools import lru_cache
@lru_cache(maxsize=None)
def f(n):
    if n < 2:
        return n
    return f(n - 1) + f(n - 2)
print(f(20))

Вывод программы

6765

Аргументы уменьшаются до 0 и 1. Без кеша одни и те же значения вычислялись бы многократно. С кешем каждое состояние n вычисляется один раз, но вложенность остаётся порядка n.

На что обратить внимание

Кеш требует хешируемых аргументов. Если функция зависит от изменённой глобальной переменной, прежние результаты кеша могут стать неверными.
