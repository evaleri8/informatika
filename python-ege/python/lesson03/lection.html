Сравнения и логические выражения

Что нужно понять

Сравнения ==, !=, <, <=, >, >= возвращают True или False. Присваивание = и сравнение == имеют разные назначения. Запись 10 <= x <= 20 проверяет принадлежность отрезку.

and требует истинности обоих условий, or — хотя бы одного, not меняет значение на противоположное. Импликация P → Q записывается (not P) or Q; эквивалентность — P == Q.

Python использует сокращённое вычисление: в d != 0 and n % d == 0 второе выражение проверяется только при ненулевом d. Побитовые & и | работают с разрядами целых и не заменяют логические операции в произвольных выражениях.

Разобранный пример

Проверим, делится ли 42 на 3 и не делится ли на 5.

n = 42
p = n % 3 == 0
q = n % 5 != 0
print(p and q)
print((not p) or q)

Вывод программы

True
True

Первое значение — одновременное выполнение двух требований. Во второй строке вывода вычислена импликация. Называя простые условия p и q, легче перенести формулу без изменения смысла.

На что обратить внимание

«Ровно одно» не означает or: используйте p != q. Для сложной формулы ставьте скобки вокруг каждого сравнения.
