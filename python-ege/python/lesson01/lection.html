Первая программа: запуск, ввод и вывод

ТеорияПрактикаДомашнее задание
Перед уроком: предварительное знание программирования не требуется. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Программа — последовательность инструкций. Python выполняет строки сверху вниз. Создайте файл main.py в редакторе установленной среды Python 3, сохраните его и запустите. Команды интерактивной консоли и содержимое файла — разные режимы работы.

print выводит значения. Текст заключается в кавычки. Знак # начинает комментарий до конца строки. Имена переменных пишут латиницей без пробелов; регистр важен. Присваивание связывает имя со значением.

input() читает строку; int(input()) превращает введённую запись целого числа в число. Для двух чисел с отдельных строк нужны два вызова input. На экзамене программа обычно выводит только требуемый ответ.

Разобранный пример

Вычислим стоимость 4 тетрадей по 35 рублей. В примере исходные данные записаны в программе, поэтому он запускается без ввода.

price = 35
count = 4
total = price * count
print(total)

Вывод программы

140

Сначала создаются price и count, затем вычисляется произведение. Для ввода с клавиатуры замените первые две строки на price = int(input()) и count = int(input()). Введите каждое число с новой строки; пример останется тем же.

На что обратить внимание

Не вводите символы приглашения >>> в файл. Кавычки вокруг числа превращают его в строку. Сохранение файла ещё не запускает программу.
