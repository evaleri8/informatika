Цикл for: диапазоны, суммы и счётчики

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

for перебирает элементы. range(start, stop, step) выдаёт целые числа, не включая stop. При одном аргументе отсчёт начинается с нуля; шаг по умолчанию равен 1.

Счётчик увеличивают на 1 за каждый подходящий объект. Накопитель суммы увеличивают на значение объекта. Начальные значения задают перед циклом, иначе результат будет сбрасываться.

При отрицательном шаге начальная граница должна быть больше конечной. Диапазон range(10, 0, -1) содержит 10 чисел от 10 до 1. Время простого прохода пропорционально количеству итераций.

Разобранный пример

Найдём число и сумму кратных 3 на отрезке [1; 20].

count = 0
total = 0
for n in range(1, 21):
    if n % 3 == 0:
        count += 1
        total += n
print(count, total)

Вывод программы

6 63

Верхняя граница равна 21, чтобы включить 20. count описывает количество, total — сумму. После обработки каждого n обе переменные относятся к уже просмотренному префиксу диапазона.

На что обратить внимание

Не путайте сумму чисел и количество чисел. Пустой range не вызывает ошибку, но тело цикла не выполнится.
