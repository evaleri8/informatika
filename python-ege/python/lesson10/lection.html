Множества, словари и частоты

Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

set хранит различные элементы без гарантированного порядка. Операции |, &, - означают объединение, пересечение и разность множеств. Проверка x in s обычно быстрая.

dict связывает ключ со значением. get(key, default) возвращает запасное значение при отсутствии ключа. Ключи должны быть хешируемыми: числа, строки и кортежи подходят, списки — нет.

Частотный словарь хранит количество появлений каждого значения. len(set(a)) равно len(a), если в списке нет повторений. Counter из collections — готовый инструмент для частот, но полезно понимать ручное накопление.

Разобранный пример

Определим частоты чисел и значения, встретившиеся ровно два раза.

a = [4, 2, 4, 7, 2, 2, 9]
freq = {}
for x in a:
    freq[x] = freq.get(x, 0) + 1
print(sorted(freq.items()))
print([x for x in sorted(freq) if freq[x] == 2])

Вывод программы

[(2, 3), (4, 2), (7, 1), (9, 1)]
[4]

Первое появление получает значение 0+1, повторные увеличивают имеющийся счётчик. sorted используется только для определённого порядка вывода. Список после if — компактный способ отбора значений.

На что обратить внимание

set уничтожает кратность: по множеству нельзя восстановить число повторений. Пустое множество — set(), а {} создаёт словарь.
