Динамическое программирование: состояния и переходы

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Динамическое программирование сохраняет ответы на подзадачи. Сначала определите смысл dp, затем начальные значения, переходы и порядок обработки.

Для числа программ исполнителя dp[x] может означать количество способов получить x. Если команды всегда увеличивают число, состояния удобно обходить по возрастанию.

Запрещённое состояние получает ноль способов. Обязательную промежуточную точку можно учесть произведением количеств путей до неё и после неё, когда траектории монотонны и иных связующих ограничений нет.

Разобранный пример

Посчитаем программы из 1 в 10 с командами +1 и *2.

dp = [0] * 11
dp[1] = 1
for x in range(1, 11):
    for y in (x + 1, x * 2):
        if y <= 10:
            dp[y] += dp[x]
print(dp[10])

Вывод программы

14

Единственный пустой путь к исходному состоянию даёт dp[1]=1. Каждая команда продолжает каждый уже построенный путь. Из 1 обе команды ведут в 2, но это разные программы, поэтому оба перехода учитываются.

На что обратить внимание

Нельзя заменять список переходов множеством, если разные команды с одинаковым результатом считаются разными программами. При циклах такой обход неприменим.
