Делители, простые числа и маски

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Делители n образуют пары d и n//d. Достаточно проверить d от 1 до isqrt(n), включая границу. У квадрата средний делитель добавляют один раз.

Простое число больше 1 и не имеет делителей от 2 до квадратного корня. Для поиска всех простых до N удобно решето Эратосфена. Если проверяется одно число, перебор делителей проще.

fnmatchcase сопоставляет строку с маской: ? означает один символ, * — любое число символов. Для числовой строки это цифры. Если требуется кратность k, перебирайте кратные k, сокращая число кандидатов.

Разобранный пример

Выведем делители 36 без повторений.

from math import isqrt
n = 36
divisors = set()
for d in range(1, isqrt(n) + 1):
    if n % d == 0:
        divisors.add(d)
        divisors.add(n // d)
print(sorted(divisors))

Вывод программы

[1, 2, 3, 4, 6, 9, 12, 18, 36]

Пара для d=6 совпадает сама с собой; множество автоматически сохраняет 6 один раз. Сортировка нужна для возрастающего вывода. Проверка до n была бы существенно дороже.

На что обратить внимание

1 не является простым. Различные делители и простые множители с кратностью — разные объекты.
