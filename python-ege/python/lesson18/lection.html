Что нужно понять

Матрицу удобно хранить списком строк. a[i][j] — элемент строки i и столбца j. Создавайте независимые строки: [[0]*m for _ in range(n)], а не [[0]*m]*n.

Для движения вправо и вниз dp[i][j] — лучший результат достижения клетки. Прибавьте её значение к лучшему допустимому предшественнику сверху или слева.

Недостижимость должна отличаться от нулевой суммы. Используйте None или бесконечность подходящего знака. Стены запрещают конкретный переход между клетками; они не равны запрету посещения всей клетки.

Разобранный пример

Найдём максимальную сумму пути по таблице 3×3 без стен.

a = [[2, 1, 4], [3, 8, 1], [1, 2, 5]]
n, m = len(a), len(a[0])
dp = [[0] * m for _ in range(n)]
for i in range(n):
    for j in range(m):
        prev = []
        if i > 0: prev.append(dp[i - 1][j])
        if j > 0: prev.append(dp[i][j - 1])
        dp[i][j] = a[i][j] + (max(prev) if prev else 0)
print(dp[-1][-1])

Вывод программы

20

Построчный обход гарантирует, что верхняя и левая клетки уже обработаны. Для стартовой клетки список предшественников пуст, поэтому учитывается только её значение. Для минимума замените max на min.

На что обратить внимание

Если конечных клеток несколько, ответ выбирают среди всех достижимых конечных клеток. Правый нижний угол не всегда единственный финиш.
