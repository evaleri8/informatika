Ветвления if, elif, else

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

if выполняет блок только при истинном условии. После условия ставят двоеточие, вложенные команды выделяют одинаковым отступом, обычно четырьмя пробелами.

В цепочке if–elif–else выполняется только первая подходящая ветка. Несколько отдельных if проверяются независимо. Вложенное ветвление применяют, когда одно решение зависит от другого.

Начинайте с точного разбиения случаев: отрицательное, нулевое, положительное; внутри и вне диапазона; равенство границе. Такое разбиение исключает пропуски и двойную обработку.

Разобранный пример

Определим знак целого числа.

x = -8
if x < 0:
    print("отрицательное")
elif x == 0:
    print("ноль")
else:
    print("положительное")

Вывод программы

отрицательное

После успешного первого условия остальные ветви пропускаются. Ветка else охватывает все оставшиеся значения, поэтому повторное условие x > 0 не нужно.

На что обратить внимание

Нельзя смешивать табуляцию и пробелы. Если переменная присваивается только в одной ветке, после if она может оказаться неопределённой.
