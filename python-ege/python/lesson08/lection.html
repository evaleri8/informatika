Строки: индексы, срезы и методы

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Строка — неизменяемая последовательность символов. Индексы начинаются с нуля, отрицательные отсчитываются с конца. s[a:b] включает a и исключает b; s[::-1] разворачивает строку.

Методы strip, split, join, replace, find, count возвращают результаты. replace не изменяет исходную строку. count считает неперекрывающиеся вхождения, find возвращает -1, если подстрока не найдена.

Строковые цифры можно сравнивать и подсчитывать без перевода всего числа. Для числовой арифметики требуется int. Перебор индексов нужен, если важны соседство и положение символов.

Разобранный пример

Подсчитаем соседние пары AB, включая возможные пересечения при других шаблонах.

s = "ABABBAAB"
count = 0
for i in range(len(s) - 1):
    if s[i:i + 2] == "AB":
        count += 1
print(count)
print(s[::-1])

Вывод программы

3
BAABBABA

Последняя начальная позиция пары — len(s)-2. Срез содержит два символа. Для шаблона AAA в строке AAAA такой подход найдёт два вхождения, а count — одно.

На что обратить внимание

Присваивание s[0] = "A" недопустимо. Не удаляйте все пробелы из входа, если они являются частью данных.
