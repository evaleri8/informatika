Жадные алгоритмы и обработка событий

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Жадный алгоритм выбирает локально лучший шаг. Его корректность требует доказательства: удобный порядок сам по себе не гарантирует оптимальность.

Для максимального числа непересекающихся интервалов подходит сортировка по времени окончания. Выбирая наиболее раннее окончание, оставляем не меньше возможностей последующим интервалам.

При моделировании событий сортируйте по времени и явно задавайте порядок одновременных событий. В условии ресурса на полуинтервалах [start,end) освобождение в момент end позволяет начать новый процесс в этот же момент.

Разобранный пример

Выберем максимальное число непересекающихся мероприятий. Касание концов разрешено.

events = [(0, 4), (1, 2), (2, 5), (4, 6), (5, 7), (7, 8)]
chosen = []
end = float("-inf")
for start, finish in sorted(events, key=lambda x: (x[1], x[0])):
    if start >= end:
        chosen.append((start, finish))
        end = finish
print(chosen)

Вывод программы

[(1, 2), (2, 5), (5, 7), (7, 8)]

Первое выбранное мероприятие заканчивается раньше других. Любое оптимальное решение можно начать с него, не уменьшая число последующих мероприятий. Затем тот же аргумент применяется к оставшейся части.

На что обратить внимание

Для максимальной суммарной стоимости мероприятий этот жадный алгоритм не подходит: требуется другая модель, например динамика. Строгая и нестрогая совместимость концов меняют условие.
