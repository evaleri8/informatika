Полный перебор и itertools

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

Вложенные циклы перебирают сочетания независимых параметров. Число вариантов — произведение размеров диапазонов. До запуска оцените эту величину.

itertools.product(alphabet, repeat=k) строит слова длины k с повторениями. permutations выбирает упорядоченные варианты без повторного выбора позиции, combinations — неупорядоченные.

Порядок product определяется порядком входного алфавита. Для алфавитного номера слова сначала расположите алфавит правильно и используйте enumerate(..., start=1). Генераторы выдают варианты постепенно; не нужно превращать их в огромный список.

Разобранный пример

Посчитаем трёхбуквенные слова над ABC, содержащие ровно одну A.

from itertools import product
count = 0
for letters in product("ABC", repeat=3):
    word = "".join(letters)
    if word.count("A") == 1:
        count += 1
print(count)

Вывод программы

12

Всего проверяется 3**3 вариантов. Кортеж символов собирается в строку, затем применяется условие. Аналитически можно выбрать место A и заполнить остальные двумя способами каждое — это независимая проверка идеи.

На что обратить внимание

permutations не означает «все слова с повторениями». Для записей чисел запрещайте ведущий ноль, если условие требует заданное число разрядов.
