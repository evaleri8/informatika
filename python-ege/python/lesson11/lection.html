Сортировка, кортежи и ключи

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

sorted создаёт новый список, list.sort изменяет исходный и возвращает None. reverse=True задаёт убывание. Кортеж — неизменяемая последовательность, удобная для записи нескольких полей.

key определяет величину для сравнения. lambda x: x[1] — короткая функция, возвращающая второе поле. Кортежи сравниваются лексикографически: сначала первые поля, при равенстве — следующие.

Для сортировки по убыванию балла и возрастанию номера используйте ключ (-балл, номер). Явно задавайте правила равенства: они часто влияют на ответ задачи.

Разобранный пример

Упорядочим участников по баллам и затем по номеру.

rows = [(12, 80), (3, 95), (7, 80), (9, 95)]
ordered = sorted(rows, key=lambda row: (-row[1], row[0]))
for number, score in ordered:
    print(number, score)

Вывод программы

3 95
9 95
7 80
12 80

Отрицание балла превращает требуемое убывание в обычное возрастание ключа. Второе поле ключа разрешает равенство баллов. Распаковка кортежа даёт двум полям понятные имена.

На что обратить внимание

Не пишите a = a.sort(): a станет None. Сортировка уничтожает исходное соседство, поэтому её нельзя применять перед поиском соседних пар исходной последовательности.
