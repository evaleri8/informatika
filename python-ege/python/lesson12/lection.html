Функции, параметры и возвращаемые значения

ТеорияПрактикаДомашнее задание
Перед уроком: предыдущие уроки Python. Номера без пометки ЕГЭ относятся к первой части курса.

Что нужно понять

def выделяет повторяемый алгоритм. Параметры получают значения при вызове. return завершает функцию и передаёт результат; print только выводит текст и не заменяет return.

Локальные переменные создаются при вызове. Лучше передавать исходные данные параметрами, а не менять глобальные значения. Одна функция должна решать ясно сформулированную задачу.

Функция может возвращать число, bool, список или кортеж. Проверять небольшие чистые функции удобно на отдельных примерах, до включения в большой алгоритм.

Разобранный пример

Напишем функцию суммы цифр неотрицательного числа.

def digit_sum(n):
    total = 0
    while n > 0:
        total += n % 10
        n //= 10
    return total

print(digit_sum(3075))
print(digit_sum(0))

Вывод программы

15
0

При n=0 цикл пустой, и возвращается 0 — верная сумма цифр. Параметр n меняется только внутри функции. Повторный вызов начинает работу с нового total.

На что обратить внимание

Без return функция возвращает None. Избегайте изменяемых значений по умолчанию вида def f(a=[]): один список будет общим для вызовов.
