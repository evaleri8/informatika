Виды деятельности в сети Интернет. Сервисы Интернета

Выбираем сетевые инструменты для поиска, общения и совместной работы

Лекция Практика Домашнее задание
Цель урока: различать основные виды деятельности в Интернете, объяснять назначение сетевых сервисов и выбирать подходящий сервис для учебной задачи.

1. Для чего люди используют Интернет

Интернет предоставляет возможности для поиска информации, общения, обучения, совместной работы, публикации материалов и получения услуг. Одну задачу часто решают с помощью нескольких сервисов: находят сведения, обсуждают их, создают общий документ и публикуют результат.

Интернет-сервис — услуга или набор возможностей, которые предоставляются пользователю через сеть. Сервис опирается на программное обеспечение и правила обмена данными — протоколы.

Вспомним предыдущие уроки: Интернет — инфраструктура связанных компьютерных сетей. Всемирная паутина (WWW) — одна из служб Интернета. Она позволяет обращаться к веб-ресурсам через браузер. Электронная почта и обмен файлами также используют Интернет, но не сводятся к просмотру веб-страниц.

Классификация условна: один сервис может объединять несколько функций. Например, образовательная платформа может содержать материалы, сообщения, видеовстречи и общие документы.

2. Сервис, программа и протокол

Эти понятия связаны, но обозначают разные стороны работы в сети.

Сервис

Какая возможность предоставляется? Например, обмен электронными письмами.

Программа

Чем пользуется человек? Например, почтовым приложением или браузером.

Протокол

По каким правилам обмениваются данными? Например, SMTP или IMAP.

Один сервис может быть доступен через сайт и отдельное приложение. При работе с веб-почтой браузер общается с её веб-сервером по HTTPS. Для передачи писем между почтовыми серверами используется SMTP. Поэтому внешний вид приложения не определяет все протоколы, на которых работает сервис.

Служба или задачаПротоколы и их назначение
Работа с веб-ресурсамиHTTP — запросы и ответы; HTTPS — HTTP с защитой соединения.
Электронная почтаSMTP — отправка и пересылка писем; IMAP — работа с письмами на сервере; POP3 — получение писем с сервера, обычно с загрузкой в почтовый клиент.
Передача файловFTP — передача файлов между клиентом и сервером. SFTP — отдельный протокол передачи файлов через защищённое соединение SSH.

В современных сервисах передача файлов также часто выполняется по HTTPS через браузер. Знать название каждого протокола для обычного скачивания не требуется; важно различать задачу, программу и правила обмена.

3. Поиск информации

Поисковая система — сервис, который помогает находить ресурсы по запросу. Она заранее собирает и обрабатывает сведения о доступных страницах, формируя поисковый индекс. При запросе пользователь обычно получает результаты из этого индекса, а не результат просмотра всего Интернета в данную секунду.

Как составить полезный запрос

  1. Определите цель. Что именно нужно узнать: определение, инструкцию, дату, документ?
  2. Выделите ключевые слова. Вместо «мне нужно что-нибудь про сеть» используйте «компьютерные сети назначение маршрутизатора».
  3. Уточните контекст. Добавьте предмет, тип материала или интересующий период.
  4. Изучите результаты. Посмотрите заголовок, адрес и описание; затем откройте подходящий материал.
  5. При необходимости измените запрос. Уберите лишнее или добавьте уточнение.
Результат поиска — указатель на источник. Краткое описание под ссылкой может быть неполным. Для учебной работы откройте сам материал и запишите его название, автора или организацию и адрес. Подробно проверку достоверности информации рассмотрим на следующем уроке.

Браузер и поисковая система — разные инструменты. Браузер открывает страницы и может передавать введённый запрос выбранной поисковой системе. При известном точном URL можно сразу обратиться к ресурсу.

4. Общение: сразу или с задержкой

Синхронное общение предполагает участие собеседников в одно время: например, разговор по видеосвязи. При асинхронном общении сообщение читают и обсуждают в удобное время: например, письмо или сообщение на форуме.

СервисОсобенностиКогда подходит
Электронная почтаАдресные сообщения, тема письма, вложения; ответ может прийти позже.Передать отчёт конкретному адресату и сохранить переписку.
МессенджерКороткие сообщения, групповые чаты, часто звонки и файлы.Быстро согласовать действия небольшой группы.
ФорумОбсуждения организованы по темам; сообщения сохраняются для последующего чтения.Собрать вопросы и ответы, к которым будут возвращаться.
ВидеоконференцияПередача речи и видео, часто демонстрация экрана; участники встречаются одновременно.Обсудить проект в реальном времени.
Социальная сетьПрофили, сообщества, публикации и общение.Публиковать новости сообщества и обсуждать их.

Мессенджер поддерживает оба режима: переписка может идти с задержками, а голосовой звонок требует одновременного участия. Выбирайте способ по задаче, а не только по названию приложения.

Из чего состоит электронное письмо

  • Адрес получателя: например, teacher@example.org. До знака @ указано имя почтового ящика в домене, после — доменное имя почтовой системы.
  • Тема: кратко обозначает содержание, например «Проект по информатике — группа 2».
  • Текст: объясняет цель обращения и нужное действие.
  • Вложение: прикреплённый файл. Вместо большого вложения можно передать ссылку на файл, проверив права доступа.

Адрес приведён как учебный пример; отправлять на него письма не нужно.

5. Совместная работа и обучение

Онлайн-редактор позволяет работать с документом через сеть. Участники могут изменять общую версию, оставлять комментарии и просматривать историю изменений, если сервис поддерживает эти функции. Общий календарь помогает согласовать сроки, а система задач — распределить обязанности.

Образовательная платформа объединяет учебные материалы, задания и средства обратной связи. Видеосвязь нужна для встречи, редактор — для совместного текста, хранилище — для файлов: даже если всё это доступно на одной платформе, функции различаются.

Пример: группа готовит доклад. Поисковая система помогает найти материалы; общий документ — написать текст; комментарии — обсудить правки; видеоконференция — провести репетицию; хранилище — передать итоговый файл. Каждому шагу соответствует своя задача.

6. Как выбрать сервис для задачи

  1. Назовите результат: найти сведения, передать файл, обсудить вопрос или создать общий документ.
  2. Определите участников и режим: кто участвует, должны ли все быть онлайн одновременно?
  3. Проверьте функции: поддерживает ли сервис нужный формат файлов, совместное редактирование, комментарии?
  4. Учтите условия: нужен ли аккаунт, какое подключение доступно, есть ли ограничения размера и доступа?
  5. Проверьте доступ к результату: смогут ли нужные участники открыть материал и выполнить свою часть работы?

Например, при неустойчивой связи удобнее обменяться текстовыми сообщениями и документами, чем проводить обязательную видеовстречу. Если требуется одновременно править один текст, пересылка отдельных копий по почте может затруднить согласование версий.
