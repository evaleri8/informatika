Виды деятельности в сети Интернет. Сервисы Интернета

Закрепляем понятия и планируем использование интернет-сервисов

Лекция Практика Домашнее задание
Порядок выполнения: задания 1–3 обязательны, дополнительное — по желанию. Обязательная часть рассчитана примерно на 20 минут. Ответы оформите в тетради или текстовом документе. Регистрироваться в сервисах и отправлять сообщения не требуется.

Задание 1. Понятия и примеры

  1. Объясните своими словами, что такое интернет-сервис. Приведите по одному примеру сервиса для поиска информации, общения и совместной работы.
  2. Распределите понятия по группам «тип сервиса», «программа-клиент», «протокол»: электронная почта, браузер, SMTP, видеоконференция, почтовое приложение, HTTPS.
  3. Объясните, почему один сервис может быть доступен и через браузер, и через отдельное приложение.

Задание 2. Выберите способ общения

Для каждой ситуации предложите подходящий тип сервиса, назовите режим общения и объясните решение.

  1. Нужно передать учителю доклад с пояснением; прочитать его можно на следующий день.
  2. Нужно немедленно обсудить распределение ролей, и все участники готовы подключиться одновременно.
  3. Нужно собирать вопросы к учебному проекту в течение недели, чтобы ответы оставались доступными группе.

Отдельно объясните, может ли мессенджер использоваться и для синхронного, и для асинхронного общения. Приведите пример каждого режима.

Задание 3. Спланируйте работу в Интернете

Класс готовит виртуальную выставку «История вычислительной техники». Нужно найти сведения, написать подписи к экспонатам, обсудить правки и представить итог.

  1. Составьте два разных поисковых запроса для поиска материалов об одном выбранном устройстве. Один запрос сделайте более общим, другой — уточняющим.
  2. Заполните таблицу. Укажите тип сервиса, а не обязательно торговое название.
ЭтапТип сервисаОжидаемый результат
Найти сведения……
Подготовить общий текст подписей……
Обсудить правки в разное время……
Представить готовую выставку……

Объясните, почему не для каждого этапа достаточно электронной почты. Укажите одно ограничение, которое учтёте при выборе сервисов: качество связи, необходимость аккаунта, размер файлов или возможности совместной работы.

Дополнительное задание. Сравнение двух способов работы

Сравните подготовку общего текста двумя способами: пересылка отдельных файлов по электронной почте и работа в онлайн-редакторе.

  1. Как участники получают изменения?
  2. Как определить актуальную версию?
  3. Как оставлять замечания?
  4. Что делать при временном отсутствии Интернета?

Сформулируйте вывод: какой способ удобнее для вашей группы и при каких условиях. Учтите, что автономная работа онлайн-редактора возможна только при наличии соответствующей функции и её предварительной настройке.

Требования к ответам

  • Сервисы, программы и протоколы различаются по назначению.
  • Выбор способа общения связан с задачей и временем участия.
  • Поисковые запросы содержат конкретные ключевые слова.
  • Для каждого этапа проекта указан ожидаемый результат.
  • У каждого выбора есть краткое объяснение.

Для повторения используйте лекцию и темы об использовании Интернета в учебниках К. Ю. Полякова и Е. А. Еремина, Л. Л. Босовой и А. Ю. Босовой. Номера параграфов уточняйте по своему изданию.
