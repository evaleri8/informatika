Компьютерные сети, IP-адресация и DNS

Построение схемы сети и анализ обращения к веб-ресурсу

Лекция Практика Домашнее задание
Цель: применить понятия «локальная сеть», «коммутатор», «маршрутизатор», «сетевой протокол», «IP-адрес» и «DNS» при решении практических задач.

Задание 1. Определите типы адресов

Распределите записи по категориям: IPv4, IPv6, доменное имя, полный веб-адрес (URL). Для каждой записи укажите её назначение.

ЗаписьТипНазначение
192.168.1.20……
2001:db8::25……
portal.example.org……
https://portal.example.org/lesson……

Дополнительно объясните, почему запись 192.168.1.20 не обозначает доменное имя.

Задание 2. Проследите обращение к сайту

Пользователь открывает браузер и вводит https://portal.example.org/lesson. Ниже перечислены действия, но их порядок нарушен.

  • А. Браузер получает ответ веб-сервера.
  • Б. DNS-резолвер получает сведения об IP-адресе.
  • В. Браузер извлекает доменное имя из URL.
  • Г. Устанавливается соединение с сервером и отправляется HTTPS-запрос.
  1. Запишите правильную последовательность букв.
  2. Укажите, для чего используются DNS, IP и HTTPS.
  3. Объясните, почему при уже сохранённом в кэше IP-адресе новый DNS-запрос может не понадобиться.
