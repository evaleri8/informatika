Лекция Практика Домашнее задание
Задания 1–3 обязательны; дополнительное — по желанию. Ответы оформите в тетради или текстовом документе. Обосновывайте выводы и сохраняйте промежуточные вычисления.

Задание 1. Типы и операции

  1. Определите типы значений 7, 7.0, "7" и True.
  2. Вычислите 17 // 5, 17 % 5 и 17 / 5; объясните различие.
  3. Почему input() без преобразования неудобен для сложения введённых целых чисел?

Задание 2. Перевод единиц

Напишите программу, которая получает неотрицательное расстояние в километрах как вещественное число и выводит метры. Подготовьте тесты для 0, 1.25 и 3.5. Укажите формулу, тип и единицы.

Задание 3. Полные группы

Есть n предметов; в коробку помещается k предметов. Вход — целые n ≥ 0 и k > 0 на отдельных строках. Программа должна вывести число полных коробок и число оставшихся предметов. Запишите решение и тесты для (20, 6), (18, 6), (0, 6).

Дополнительное задание

Положительное четырёхзначное число нужно записать в обратном порядке. С помощью целочисленных операций выделите цифры и выведите их в обратном порядке без пробелов. Объясните, что получится для числа 1200 и почему это отличается от числового значения 21.
