Язык программирования. Основные конструкции языка программирования. Типы данных

Основные понятия, примеры и способы решения

Лекция Практика Домашнее задание
Цель: читать и писать небольшие программы Python 3 со вводом, присваиванием, вычислениями и выводом; различать основные типы данных.

1. Язык и среда выполнения

Язык программирования задаёт правила записи команд и их смысл. Для выполнения программы используют реализацию языка и среду запуска. Здесь применяется Python 3. Программу сохраняют в файле с расширением .py или выполняют в учебной среде, выбранной учителем.

Каждая инструкция выражает действие. Комментарий начинается с # и служит пояснением. Для начала удобно использовать латинские имена переменных, отражающие назначение: length, total, count. Регистр важен: total и Total — разные имена.

2. Типы данных

ТипНазначениеПримеры записи
intЦелые числа12, 0, -7
floatЧисла с плавающей точкой2.5, -0.75
strСтроки символов"сеть", "12"
boolЛогические значенияTrue, False

Тип принадлежит объекту; имя переменной связывается с объектом присваиванием. Запись x = 5 не требует предварительно объявлять тип. Однако операция должна быть допустима для данных типов: число и строку нельзя складывать как два числа без явного преобразования.

3. Ввод и преобразование

name = input()
print("Здравствуйте,", name)

input() возвращает строку. Для числовых вычислений используют преобразование int() или float().

a = int(input())
b = int(input())
print(a + b)

Каждое input() здесь читает отдельную строку. Для a = 8 и b = 3 программа выводит 11. Если оставить строковый ввод без преобразования, сложение строк "8" + "3" даст "83". В записи вещественного числа для Python используют точку; int("3.5") не является корректным преобразованием целой записи.

4. Арифметические операции

ОператорДействиеПример
+ − *Сложение, вычитание, умножение7 + 2 → 9
/Обычное деление7 / 2 → 3.5
//Деление с округлением вниз7 // 2 → 3
%Остаток7 % 2 → 1
**Возведение в степень3 ** 2 → 9

Скобки задают нужный порядок. Без скобок умножение и деление выполняются раньше сложения. Для целого неотрицательного n последняя десятичная цифра равна n % 10, а удаление последней цифры выполняется как n // 10. Делить на ноль нельзя.

5. Разобранная программа

Вход: положительные длина и ширина прямоугольника, каждая в отдельной строке. Выход: площадь и периметр.

length = float(input())
width = float(input())
area = length * width
perimeter = 2 * (length + width)
print(area)
print(perimeter)

Для входа 3 и 2 результат — 6.0 и 10.0 на отдельных строках. В этой программе соблюдение условия положительности предполагается. Проверку условий добавим в следующем уроке.

6. Точность и форма результата

Числа float представляют многие десятичные дроби приближённо. Небольшое расхождение в последнем разряде может быть особенностью представления, а не ошибкой алгоритма. Для вывода двух знаков после точки используют, например, print(f"{area:.2f}"); это форматирование вывода, а не изменение математической модели.

При подготовке теста учитывают тип результата: число предметов целое, длина может быть дробной, название — строка. Изменение расширения файла на .py не превращает произвольный текст в корректную программу.

Проверяйте преобразование ввода, порядок действий и единицы измерения. Сначала вычисляется правая часть присваивания, затем обновляется переменная.
