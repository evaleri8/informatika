Лекция Практика Домашнее задание
Используйте Python 3 в установленной или рекомендованной учителем среде. При отсутствии компьютера запишите программы и выполните ручную трассировку. Каждое число во входных данных вводится с новой строки.

Задание 1. Строки и числа

a = input()
b = input()
print(a + b)
  1. Определите результат для строк 12 и 5.
  2. Измените программу так, чтобы вычислялась числовая сумма двух целых чисел.
  3. Покажите различие на тех же входных данных и объясните типы.

Задание 2. Сумма и среднее

Напишите программу: вход — три целых числа на отдельных строках; выход — сумма и среднее арифметическое на отдельных строках.

  1. Выберите имена переменных и типы.
  2. Составьте программы и тесты для троек (2, 4, 6), (−3, 0, 3), (1, 1, 2).
  3. В отчёте укажите ожидаемые и полученные результаты; не округляйте среднее без требования.

Задание 3. Цифры числа

На вход подаётся целое трёхзначное положительное число от 100 до 999. Найдите сотни, десятки и единицы, выведите их сумму. Для выделения цифр используйте // и %.

  1. Запишите алгоритм и программу.
  2. Проверьте входы 100, 507 и 999.
  3. Объясните, почему операция n // 10 сама по себе не даёт цифру десятков трёхзначного числа.

Оформление результата
