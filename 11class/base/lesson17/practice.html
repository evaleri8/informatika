Циклы с условием. Циклы по переменной

Применяем знания и объясняем ход решения

Лекция Практика Домашнее задание
Работайте на Python 3 или выполните ручную трассировку. Результат: три программы и таблицы тестов. Условия допустимости входа соблюдаются.

Задание 1. Сумма диапазона

Вводится целое n ≥ 0. Циклом for вычислите сумму чисел от 1 до n включительно.

  1. Запишите начальное значение суммы и границы range.
  2. Для n = 4 выполните таблицу «k — сумма после прибавления».
  3. Проверьте n = 0, 1 и 5.
  4. Сравните результат с формулой n(n + 1) // 2.

Задание 2. Сумма цифр

Вводится целое n ≥ 0. Циклом while найдите сумму десятичных цифр. На каждом шаге извлеките последнюю цифру через %, прибавьте к сумме и удалите её через //.

  1. Сохраните исходное число в отдельной переменной.
  2. Проверьте входы 0, 7, 507 и 999.
  3. Объясните, почему цикл завершается и какой результат получается для нуля.

Задание 3. Ввод до нуля

Целые числа поступают по одному на строке; последовательность обязательно заканчивается нулём. Ноль не учитывается. Найдите количество положительных чисел среди введённых.

  1. Выберите условие продолжения и место чтения следующего числа.
  2. Проверьте наборы: только 0; 2, −1, 5, 0; −3, −2, 0.
  3. Объясните, какая команда предотвращает повторную обработку одного и того же значения.

Оформление результата

Приведите код и тесты, укажите значения сумм и счётчиков на выбранных шагах. Нулевые и пустые случаи не пропускайте.
