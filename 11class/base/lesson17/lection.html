Урок №17 · Лекция

Циклы с условием. Циклы по переменной

Основные понятия, примеры и способы решения

Лекция Практика Домашнее задание
Цель: выбирать между циклом с условием и перебором значений, накапливать сумму и количество, обеспечивать завершение цикла.

1. Зачем нужен цикл

Цикл описывает повторное выполнение блока команд. Перед циклом задают начальные значения, внутри выполняют полезное действие и изменяют данные, от которых зависит продолжение.

В Python цикл while повторяет тело, пока условие истинно. Цикл for последовательно получает элементы заданной последовательности; в задачах с целыми значениями часто используют range.

2. Цикл с условием

x = 1
while x <= 4:
    print(x)
    x = x + 1

Программа выводит 1, 2, 3, 4. Условие проверяется до тела, поэтому при начальном ложном условии тело не выполнится ни разу. Если забыть увеличение x, условие останется истинным и цикл не завершится.

3. Цикл по значениям

for k in range(1, 5):
    print(k)

Вывод такой же. range(start, stop, step) задаёт целые значения до stop, не включая stop. По умолчанию шаг равен 1; при одном аргументе начало равно 0. Нулевой шаг недопустим.

4. Сумма и счётчик

Для суммы начальное значение обычно 0; для произведения — 1. Счётчик увеличивают только при нужном событии. Пример: суммируем и считаем чётные числа от 1 до n включительно; вход n — целое неотрицательное число.

n = int(input())
total = 0
count = 0
for k in range(1, n + 1):
    if k % 2 == 0:
        total += k
        count += 1
print(total)
print(count)

При n = 5 обрабатываются 2 и 4: сумма 6, количество 2. Запись total += k означает прибавление к текущей сумме. Если обнулить total внутри тела, накопление будет потеряно.

5. Условие завершения и обработка цифр

Для неотрицательного целого числа можно удалять последнюю цифру командой n //= 10. При n > 0 число уменьшается и в итоге становится 0. Пример подсчёта числа десятичных цифр, включая особый вход 0:

n = int(input())
if n == 0:
    digits = 1
else:
    digits = 0
    while n > 0:
        digits += 1
        n //= 10
print(digits)

Соблюдение n ≥ 0 здесь предполагается. При n = 507 цикл выполняется трижды. Если исходное число понадобится позднее, для изменения используют отдельную рабочую переменную.

6. Ввод до признака окончания

Если количество значений заранее неизвестно, можно читать их до специального значения — признака окончания. Нужно явно указать, входит ли оно в обработку. Ноль, завершающий ввод, обычно не является элементом набора для вычислений.

Первое значение читают перед проверкой. После обработки внутри цикла читают следующее. Пропущенное обновление способно привести к бесконечному повторению. Гарантия окончания ввода является частью условия.

7. Выбор и проверка цикла

  • Известен диапазон значений — обычно удобен for с range.
  • Повторение зависит от изменяющегося состояния — удобен while.
  • Проверьте ноль повторений, один повтор и обычный набор.
  • Проверьте включение правой границы, начальные значения и изменение состояния.
Число повторений тела и число проверок условия могут различаться. Для while с m проходами и обычным завершением условие проверяется m + 1 раз.
