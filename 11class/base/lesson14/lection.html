Урок №14 · Лекция

Анализ алгоритмов. Этапы решения задач на компьютере

Основные понятия, примеры и способы решения

Лекция Практика Домашнее задание
Цель: выделять этапы решения задачи на компьютере, прослеживать выполнение алгоритма и оценивать число повторяемых действий.

1. Задача, алгоритм, программа

Алгоритм — понятная исполнителю последовательность точных команд для решения задачи. Для учебных алгоритмов важны определённость команд, последовательность отдельных шагов и завершение за конечное число шагов для допустимых исходных данных.

Программа — запись алгоритма на языке программирования. Один алгоритм может иметь реализации на разных языках; одна и та же задача может решаться разными алгоритмами.

Исполнитель действует по командам, а не по неявному замыслу автора. Поэтому заранее задают допустимые входные данные и ожидаемый результат. Например, деление двух чисел требует отдельно оговорить ненулевой делитель.

2. Этапы решения

ЭтапЧто необходимо определить
ПостановкаЧто известно, что найти, в каком виде получить результат?
ФормализацияКакие величины, ограничения и зависимости описывают задачу?
Разработка алгоритмаКакие команды и в каком порядке выполняются?
ПрограммированиеКак выразить команды средствами выбранного языка?
Тестирование и отладкаСовпадает ли результат с ожидаемым, где причина ошибки?
АнализРешает ли программа задачу при всех оговорённых условиях, подходят ли затраты ресурсов?

3. Базовые конструкции

Следование

Действия выполняются одно за другим.

Ветвление

В зависимости от условия выбирается действие.

Цикл

Одни и те же действия повторяются по правилу.

Алгоритм записывают словами, псевдокодом, блок-схемой или программой. В блок-схеме прямоугольник обычно обозначает обработку, параллелограмм — ввод или вывод, ромб — проверку условия. У ветвей подписывают результаты проверки.

4. Трассировка

Трассировка — последовательное выполнение команд с записью значений переменных. Рассмотрим обмен значений x = 5 и y = 2 через временную переменную t.

ШагКомандаxyt
НачалоИсходные значения52не задана
1t = x525
2x = y225
3y = t255

Знак = в этих командах означает присваивание: сначала вычисляется правая часть, потом результат сохраняется слева. Если записать только x = y, затем y = x, старое значение x будет потеряно.

5. Тестирование и ошибки

Тест содержит входные данные и ожидаемый результат, полученный независимо от проверяемой программы. Выбирают обычные, граничные и особые допустимые случаи. Данные вне области допустимости проверяют, если задача требует их обработки.

Вид ошибкиПример
СинтаксическаяКоманда записана с нарушением правил языка.
Ошибка выполненияВо время работы возникло деление на ноль.
ЛогическаяПрограмма завершилась, но вместо суммы вычислила разность.

Несколько успешных тестов повышают уверенность, но не доказывают правильность для всех возможных входов. Нужно также понимать ход алгоритма и его ограничения.

6. Оценка числа действий

Для суммы целых чисел от 1 до n при n ≥ 0 можно выполнить n сложений в цикле. Можно использовать формулу n(n + 1)/2. При подсчёте арифметических операций второй вариант имеет постоянное число действий, а число сложений первого растёт вместе с n.

Это оценка в выбранной модели, а не обещание одинакового реального времени: представление чисел, ввод и среда тоже влияют на выполнение. При анализе важно назвать, что именно считается.

Сначала обеспечивают правильность и завершение для допустимых данных, затем сравнивают затраты. Быстрый неверный ответ не решает задачу.
