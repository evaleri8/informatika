Лекция Практика Домашнее задание
Задания 1–3 обязательны; дополнительное — по желанию. Ответы оформите в тетради или текстовом документе. Обосновывайте выводы и сохраняйте промежуточные вычисления.

Задание 1. Этапы решения

  1. Для перевода расстояния из километров в метры задайте вход, выход, ограничения и формулу.
  2. Запишите алгоритм и три теста, включая нулевое расстояние.
  3. Объясните отличие алгоритма от программы.

Задание 2. Найдите ошибку

Для среднего арифметического двух чисел автор записал r = a + b / 2. Объясните логическую ошибку, исправьте формулу и предложите тест, на котором различие заметно. Сформулируйте ожидаемый ответ.

Задание 3. Анализ выполнения

Исходно x = 3. Пять раз выполняется x = x + 2. Запишите все промежуточные значения и итог. Сколько сложений будет при n повторениях? Сформулируйте итоговое значение через n.

Дополнительное задание

Сравните два способа обмена двух чисел: через временную переменную и через сумму и разности. Запишите оба алгоритма, их трассировку и условие, при котором арифметический вариант может быть неудобен в языке с ограниченной разрядностью чисел.
