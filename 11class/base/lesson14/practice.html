Анализ алгоритмов. Этапы решения задач на компьютере

Применяем знания и объясняем ход решения

Лекция Практика Домашнее задание
Работу можно выполнить без компьютера. Результат: постановка задачи, алгоритм, трассировка и набор тестов.

Задание 1. Пройдите этапы решения

Даны длина и ширина прямоугольника — положительные числа. Нужно найти площадь и периметр.

  1. Опишите вход, выход и допустимые данные.
  2. Запишите математическую модель.
  3. Составьте словесный алгоритм или блок-схему.
  4. Придумайте три допустимых теста и вычислите ожидаемый результат вручную.

Задание 2. Выполните трассировку

Исходно a = 4, b = 7. Команды: t = a + b; a = t − a; b = t − b.

  1. Составьте таблицу значений после каждой команды.
  2. Опишите итоговое преобразование пары.
  3. Повторите для a = 0, b = −3.
  4. Почему порядок команд здесь существенен?

Задание 3. Проанализируйте повторения

Алгоритм устанавливает s = 0, затем для каждого целого k от 1 до n включительно прибавляет k к s. Вход n — целое неотрицательное число.

  1. Найдите результат и число сложений при n = 0, 1, 5.
  2. Сравните число арифметических действий с вычислением n(n + 1)/2.
  3. Объясните, почему n = 0 нужно включить в тесты.
  4. Если по ошибке перебрать числа до n − 1, на каком из ваших тестов ошибка обнаружится?

Оформление результата

В трассировке показывайте промежуточные значения, в тестах — и вход, и ожидаемый выход.
