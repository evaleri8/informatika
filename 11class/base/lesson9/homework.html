Лекция Практика Домашнее задание
Задания 1–3 обязательны; дополнительное — по желанию. Ответы оформите в тетради или текстовом документе. Обосновывайте выводы и сохраняйте промежуточные вычисления.

Задание 1. Модели одного объекта

  1. Для школьной библиотеки предложите две разные цели моделирования.
  2. Для каждой укажите существенные свойства и форму информационной модели.
  3. Приведите пример свойства, которое важно для одной цели и несущественно для другой.

Задание 2. Движение по модели

Транспорт движется с постоянной скоростью 60 км/ч, остановок нет; t — время от начала движения, 0 ≤ t ≤ 4 часа.

  1. Запишите зависимость расстояния от времени.
  2. Составьте таблицу для t = 0; 0,5; 1; 2; 4.
  3. Объясните, как изменится описание, если появится остановка.
  4. Назовите ограничения такой модели реальной поездки.

Задание 3. Представление данных

  1. Выберите форму для точного расписания, сравнения числа книг по жанрам и отображения связей между кабинетами.
  2. Для каждого выбора объясните, почему эта форма удобна.
  3. Чем проверка вычислений отличается от проверки адекватности модели?

Дополнительное задание

Предложите модель накопления средств при постоянном еженедельном пополнении без расходов. Задайте вымышленные данные, запишите формулу и исследуйте достижение выбранной суммы.
