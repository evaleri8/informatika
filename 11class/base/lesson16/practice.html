Урок №16 · Практическая работа

Ветвления. Составные условия

Применяем знания и объясняем ход решения

Лекция Практика Домашнее задание
Напишите программы на Python 3. Для каждого задания подготовьте таблицу «вход — ожидаемый результат — полученный результат». При отсутствии компьютера выполните ручную трассировку.

Задание 1. Максимум и равенство

Вводятся два целых числа a и b на отдельных строках. Выведите большее; если числа равны, выведите сообщение «Равны». Предусмотрите три исхода и тесты для a > b, a < b и a = b, включая отрицательные значения.

Задание 2. Учебный тариф доставки

Вход — вещественное расстояние d. При d < 0 выводится «Ошибка данных». Для 0 ≤ d ≤ 5 стоимость 100; для 5 < d ≤ 15 — 200; для d > 15 — 350 условных рублей. Это вымышленные условия.

  1. Запишите цепочку if–elif–else без пересечения диапазонов.
  2. Проверьте значения −1, 0, 5, 5.1, 15 и 15.1.
  3. Поясните, куда относятся граничные точки 5 и 15.

Задание 3. Составное условие

Вводится целое x. Требуется вывести «Да», если x принадлежит отрезку [−5; 5] и делится на 2 без остатка, иначе «Нет».

  1. Составьте условие с and и операцией %.
  2. Подготовьте тесты на обе границы, внутри и вне диапазона; отдельно рассмотрите 0.
  3. Запишите условие противоположного результата с помощью not.

Оформление результата

В отчёте должны быть код, граничные тесты и объяснение условий. Названия торговых сервисов или реальные тарифы не используются.
