Урок №16 · Лекция

Ветвления. Составные условия

Основные понятия, примеры и способы решения

Лекция Практика Домашнее задание
Цель: реализовывать выбор действий с помощью if, elif и else; составлять логические условия и проверять границы диапазонов.

1. Условие и сравнение

Условие даёт логический результат True или False. В Python сравнивают значения операторами ==, !=, <, <=, >, >=. Знак = используется для присваивания, а == — для проверки равенства.

2. Полное и неполное ветвление

x = int(input())
if x >= 0:
    print("Неотрицательное")
else:
    print("Отрицательное")

После условия ставится двоеточие, тело ветви выделяется отступом; в примерах — четыре пробела. При истинном условии выполняется блок if, иначе — блок else. Если действие нужно только при истинном условии, блок else можно не писать.

3. Несколько вариантов

x = int(input())
if x > 0:
    print("Положительное")
elif x < 0:
    print("Отрицательное")
else:
    print("Ноль")

В цепочке if–elif–else выполняется первая ветвь с истинным условием; если таких нет, выполняется else. Это отличается от нескольких отдельных if, у которых могут выполниться несколько блоков.

4. Составные условия

ОперацияКогда истиннаПример
andОбе части истинны.x >= 10 and x <= 20
orХотя бы одна часть истинна.x < 10 or x > 20
notИсходное условие ложно.not (x >= 10 and x <= 20)

Первое условие задаёт отрезок [10; 20], второе — значения вне него. В Python также допустимо 10 <= x <= 20. Для ясности сложные части заключают в скобки. Приоритет операций: сравнения, затем not, and и or.

5. Пример с границами

В учебной задаче результат от 0 до 100 баллов включительно. От 80 — «Высокий», от 50 до 79 — «Достаточный», ниже 50 — «Требуется доработка». Недопустимое значение обрабатывается отдельно.

score = int(input())
if score < 0 or score > 100:
    print("Ошибка данных")
elif score >= 80:
    print("Высокий")
elif score >= 50:
    print("Достаточный")
else:
    print("Требуется доработка")

Во второй проверке диапазон уже ограничен предыдущими условиями, поэтому повторять верхние границы не требуется. Если поменять порядок порогов 50 и 80 без изменения условий, высокие результаты попадут в раннюю ветвь.

6. Проверка ветвлений

СлучаиДля чего нужны
Ниже, на границе и выше порогаОбнаружить ошибку < вместо <= или наоборот.
Все ветвиПроверить, достижим ли каждый предусмотренный результат.
Недопустимые значенияПроверить отказ или сообщение, если это требует условие.
Особые точкиНоль, равные значения, концы диапазона.

Для примера полезны −1, 0, 49, 50, 79, 80, 100 и 101. Ожидаемый результат определяют по условию задачи до запуска программы. Не следует считать вход допустимым только потому, что программа смогла с ним выполнить вычисления.

Для принадлежности диапазону обычно требуется and; для выхода за его границы — or. Читайте условие словами и проверяйте примеры с обоих концов.
