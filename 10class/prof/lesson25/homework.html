Лекция Практика Домашнее задание

Задание 1. Основные понятия

Дайте определения следующим понятиям:

  1. Информация.
  2. Данные.
  3. Знания.
  4. Информационный процесс.

Объясните различие между данными и знаниями.

Задание 2. Информационные процессы

Рассмотрите следующие ситуации:

  1. Растение реагирует на изменение продолжительности светового дня.
  2. Компьютер сохраняет результаты вычислений в файл.
  3. Учитель передаёт учащимся сведения о результатах контрольной работы.
  4. Навигационная система определяет маршрут на основе данных о дорогах.

Для каждой ситуации:

  • определите происходящие информационные процессы;
  • укажите, к какой системе относится рассматриваемый пример: природной, технической или социальной;
  • кратко обоснуйте свой ответ.

Требования к выполнению

  • Ответы должны содержать корректные определения и обоснования.
  • При выполнении заданий необходимо использовать изученную терминологию.
  • Схемы должны иметь подписи основных элементов.
  • Работу выполнять в тетради.
